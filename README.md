# My Agentic AI Engineering Journey

I'm a data engineer learning to build AI agents, following a 7-layer roadmap
(Model → Prompt → Context → Harness → Loop → Graph → Ontology). This repo holds
the roadmap, my notes for each phase, and the code for every mini-project.

Notes are written so a complete beginner could follow along.
